## Description

**deboa-multipart** adds multipart form handling to deboa runtime crates.

## Install

Either run from command line:

`cargo add deboa-tokio`

Or add to your `Cargo.toml`:

```toml
deboa-tokio = { version = "0.1.1", features = ["multipart"] }
```

## Crate features

- single-threaded
- multi-threaded
